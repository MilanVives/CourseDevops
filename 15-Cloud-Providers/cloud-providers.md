# Les 15 – Cloud Providers & Cloud Services

> 🚧 **Placeholder** — inhoud nog te schrijven.

## 🎯 Doel van de les

Een algemeen overzicht van cloud computing als fundament voor de rest van het Cloud Infrastructure-traject, vóór de studenten met Infrastructure as Code (IaC) en Kubernetes aan de slag gaan.

## 🧩 Onderwerpen

- **Wat is cloud computing?** On-premise vs cloud, voor- en nadelen.
- **Service-modellen**: IaaS, PaaS, SaaS — waar past Kubernetes/containers in dit plaatje?
- **Belangrijkste cloudproviders**: AWS, Azure, GCP, en kleinere/goedkopere spelers (Linode/Akamai, DigitalOcean, Oracle Cloud, Hetzner) — vergelijking van diensten en pricing-modellen.
- **Kerninfrastructuur**: compute (VM's), storage (object/block/file), networking (VPC, load balancers), managed databases.
- **Regions & availability zones**: latency, redundantie, data-soevereiniteit (bv. EU-datacenters).
- **Kostenbeheer**: pay-as-you-go, reserved instances, voucher/credit-programma's voor studenten.
- **Shared responsibility model**: wat beheert de provider, wat beheer jij?
